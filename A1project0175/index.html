How i built it

Reflection

ปัญหาที่ผมพบระหว่างการพัฒนาเว็บไซต์คือ link external css style ทีใส่ไว้ไม่สามารถใช้ได้และวิดีโอก็ไม่แสดง
ซึ่งปัญหาเกิดจากการใส่ Source วิดีโอไว้ผิดที่ และใส่ชื่อcss styleผิดเลยทำให้เปิดไม่ได้ผมแก้ปัญหาโดยการย้อนดูโค้ด และหาตำแหน่งวิดีโออีกรอบ
จากการทำงานนี้ทำให้ผมเข้าใจเกี่ยวกับการตกแต่งและการสร้างเว็บไซต์มากขึ้น
หากได้พัฒนางานนี้ต่อผมอยากให้งานนี้มีสีสันมากกว่านี้และจัดให้เป็นระเบียบมากกว่าเดิมเพราะผมยังไม่รู้วิธีการจัดระเบียบหน้าเว็บไซต์ให้ดูเป็นระเบียบมากกว่านี้
